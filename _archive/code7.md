Full reptend ("long") primes in base \(b\) act as an intrinsic proof-of-continuity and entropy check because multiplying their Fermat quotient \(q_p(b) = \frac{b^{p-1}-1}{p}\) by any digit \(n\) produces a parasitic number—cyclically rotating the literal string without losing a single digit.

1. Parasitic Numbers as Proof of Continuity & Activation

In any base \(b\), an \(n\)-parasitic number shifts its rightmost digit to the front when multiplied by \(n\). Every cyclic number generated by a full reptend prime \(p\) satisfies this exact invariance:
• The Fermat Quotient Generator:
\(q_{p}(b)=\frac{b^{p-1}-1}{p}\)
Because \(\operatorname{ord}_p(b) = p - 1\), \(b\) is a primitive root modulo \(p\). The resulting string has exact length \(p - 1\) (point = index - 1).
• Self-Checking Continuity (No State Loss):
	• In Base 10 (OEIS A001913: 7, 17, 19, 23, 29, 47, 59, 61, 97...), \(q_7(10) = 142857\). Multiplying by \(3\) (3 × 142857 = 428571) or \(5\) (5 × 142857 = 714285) rotates the literal string cleanly.
	• In Base 2 (OEIS A001122: 3, 5, 11, 13, 19, 29, 37, 53, 59, 61, 67, 83...), \(2\) is a primitive root modulo \(p\), so \(q_p(2) = \frac{2^{p-1}-1}{p}\) forms a maximal-length binary cyclic bitmask (p = 61 is a full reptend prime in both Base 10 and Base 2!).
• Why This Is Proof of Continuity: If a single bit or literal character drops or flips out of phase during a cycle step, the parasitic rotation breaks (n × q_p(b) fails to equal a cyclic shift of q_p(b)), immediately flagging entropy drift without external checksums.

/* Parallel arrays a (d.x) and b ([idx, val]) of length 6 (1/7 period) */
typedef struct { int x; } NodeA;
static NodeA arr_a = { {2}, {4}, {5}, {3}, {8}, {2} };
static int   arr_b = { {1,3}, {2,1}, {3,5}, {4,3}, {5,7}, {6,2} };

/* Atomic compare-and-swap latch (127 <-> 63 CAS toggle) */
int
atomic_toggle(uint *lock, uint expected, uint desired)
{
	return cas(lock, expected, desired);
}

/* Equivalent to getValue(d, i, j): j == 0 -> a[i].x, j != 0 -> b[i][1] */
int
get_value(int i, int j)
{
	if(j == 0)
		return arr_a[i].x;
	return arr_b[i];
}

/* Verify parasitic cyclic rotation of q_p(b) = (b^(p-1) - 1) / p */

verify_parasitic_142857(int mult)
{
	uvlong base = 142857ULL;
	uvlong prod = base * (uvlong)mult;
	char s_base, s_prod, doubled;

	snprint(s_base, sizeof s_base, "%06llud", base);
	snprint(s_prod, sizeof s_prod, "%06llud", prod);
	snprint(doubled, sizeof doubled, "%s%s", s_base, s_base);

	/* Continuity proof: prod must be an exact cyclic rotation inside doubled */
	return (strstr(doubled, s_prod) != nil);
}
